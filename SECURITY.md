# Security Policy

## Supported Versions

Only the latest branch of `Corpo-Recon` is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do NOT create a public issue. 
Instead, reach out directly to the maintainer via the email associated with the GitHub account (Piyush / Kurosyss).

Please include:
- A description of the vulnerability.
- Steps to reproduce.
- Potential impact.

You should receive a response within 48 hours.

## Ethical Hacking & Responsible Use

This tool is designed for **authorized** Attack Surface Management (ASM) and Corporate Risk Analysis. 
Do not use this tool against targets without explicit, written consent from the organization.
